# Akasha Studio with Antigravity AI Engine

**Akasha Studio** is a full-stack, cloud-native web builder powered by the Antigravity autonomous AI engine, local Antigravity workspace persistence, MongoDB GridFS cloud storage, and automated build self-healing.

---

## ⚡ Core Features

- **Direct Antigravity Brain Missions**: Issue tasks directly to Antigravity without needing third-party API keys (Zero-Key Active).
- **💾 Save to Antigravity Workspace**: Export and persist all generated pages, components, schemas, and configurations directly into your active Antigravity IDE workspace.
- **☁ MongoDB GridFS Cloud Sync**: Chunked binary streaming for media assets and cloud storage backup.
- **Full Studio Dashboard**: Live token telemetry, system diagnostics, and interactive control canvas.
- **Self-Healing Build Diagnostics**: Continuously verifies TypeScript compilation and auto-repairs code errors.
- **Live Sandbox Preview**: Embedded Vite + React app preview running on port `5173`.
